# Economy, Discovery, and Marketplaces

## Pokoin
- [ ] Define issuance, sinks, transfer, refunds, expiration and abuse cases.
- [ ] Append-only ledger plus balance projection.
- [ ] Transactions/idempotency for earning, spending, refunds and grants.
- [ ] Current planning assumption: 15% fee on relevant creator transactions, pending final policy/payment/legal review.
- [ ] Economy tuning must be measured, versioned, observable and reversible.
- [ ] Server-full priority placement is a product rule only after fairness/abuse review; it cannot bypass safety or hard capacity.
- [ ] Reconcile payment receipts with internal ledger; audit manual adjustments.

## Achievements
- [ ] Schema and server-side unlock validation.
- [ ] Planning idea: 25 free achievements per developer, paid additional capacity; validate cost and abuse implications.
- [ ] Idempotent unlocks and migration policy.

## Marketplaces
- [ ] Keep creator asset/plugin marketplace separate from PokoX player marketplace.
- [ ] Listing, ownership, licensing, takedown, refunds and version rules.
- [ ] Defer public launch until moderation/fraud/publisher checks exist.
- [ ] Executable plugins require review and permission gates.

## Discovery
- [ ] Genre taxonomy, search, sorting and pagination.
- [ ] Similarity using tags and permitted activity.
- [ ] Ranking diversity and abuse resistance.
- [ ] Explainable recommendation reasons and user controls.
- [ ] Measure impressions/clicks/joins without unnecessary collection.

## Gate
Currency mutations are auditable/idempotent; marketplace ownership is server-enforced; discovery can be measured and tuned.

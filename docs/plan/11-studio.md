# Poko Studio

## Main creator workspace
- [ ] Create/open project and recent projects.
- [ ] Scene viewport and camera navigation.
- [ ] Hierarchy and inspector.
- [ ] Asset import/browser.
- [ ] Mute script editor and diagnostics.
- [ ] Output/log panel.
- [ ] Play/pause/stop/restart.
- [ ] Save/reopen, recovery and undo/redo.
- [ ] Publish immutable version, view history, rollback.

## Object editing
- [ ] Select/multi-select, transform gizmos, snapping, duplicate/delete.
- [ ] Parenting/reparenting with validation.
- [ ] Inspector edits update scene immediately.
- [ ] Code-like property access and normal script editing coexist without duplicate state.
- [ ] Inspector uses metadata and reflects runtime/API state.

## Creator loop
Create project → add objects/assets → attach Mute → playtest → inspect errors → save → validate/package → publish → verify → rollback if needed.

## Plugins
- [ ] Manifest, permissions, versioning and compatibility.
- [ ] Sandbox execution; signed/reviewed privileged extensions.
- [ ] Separate Studio marketplace from PokoX player marketplace.
- [ ] Defer public plugin marketplace until publishing/safety are mature.

## Gate
Creator can build a small playable scene, script it, playtest, save, reopen and publish without manually editing internal package files.

- **Architecture decisions**: Check `docs/decisions/` for recorded ADRs
- **Task priorities**: Refer to TASKS.md and STATUS.md
- **Build issues**: See the Stage 1 Foundation contract at `docs/roadmap/stage-1-foundation.md`
- **Security requirements**: Review `docs/12-security/`

For additional help, contact the engineering team via internal channels.

### For Users

PokoX is currently in development. Public support channels will be established before the first stable release.

## Bug Reports

Authorized contributors can report bugs through the project's issue tracker. Please include:

- Clear description of the bug
- Steps to reproduce
- Expected vs actual behavior
- Environment details (OS, toolchain versions)
- Relevant logs or error messages
- Task ID if related to specific work

## Feature Requests

Feature requests should be submitted through the internal product planning process. Public feature requests will be accepted via a dedicated forum after initial release.

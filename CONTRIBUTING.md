# Contributing to Poko

Thank you for your interest in contributing to Poko. As this is a proprietary project, contributions are currently limited to authorized team members.

## For Authorized Contributors

### Getting Started

1. Ensure you have been granted access to the repository
2. Clone the repository:
   ```bash
   git clone https://github.com/Raft-The-Crab/PokoX.git
   ```
3. Set up your development environment according to the README
4. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```

### Development Workflow

1. Make your changes following the project's coding standards
2. Test your changes thoroughly
3. Ensure all tests pass
4. Commit your changes with clear, descriptive messages
5. Push your branch and create a pull request

### Code Style

- **Rust**: Follow `rustfmt` formatting
- **C/C++**: Follow project's existing style (4 spaces, snake_case)
- **TypeScript**: Follow Prettier formatting
- **Kotlin**: Follow Android Kotlin style guide

### Testing

- Write unit tests for new functionality
- Ensure existing tests continue to pass
- Test on both Windows and Android when applicable

### Documentation

- Update relevant documentation when changing behavior
- Add comments for complex logic
- Keep README and planning documents up to date

## External Contributions

At this time, external contributions are not accepted. This may change in the future as the project matures.

## Questions

For questions about contributing, please contact the project maintainers through official channels.
